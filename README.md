# Proletarian Power Guitar pedal
## an open sourced, ancom-themed overdrive guitar pedal.

What is the Proletarian Power?
It is an overdrive pedal PCB designed with a hardclipping switch and a tone-knob, primarily made for me to learn electronics design.
