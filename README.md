# Proletarian Power Guitar pedal
## an open sourced, ancom-themed overdrive guitar pedal.

This was an incredibly scuffed attempt at making an electric guitar pedal as a way to learn and document my electrical engineering journey as a creator.

The really crappy pedal was very loosely based off of the tube-screamer schematic, with a notable addition of a hard-clipping switch, or as I like to call it, the fun switch.
